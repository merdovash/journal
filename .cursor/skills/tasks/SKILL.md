# Tasks и версия проекта

## Когда применять

- Команда `/tasks` или явное «выполни задачи»
- Закрытие / доработка пункта из `TASKS.md`
- Любой коммит по задаче из `TASKS.md`

## Порядок работы

1. Читай `TASKS.md`. Бери незакрытую задачу (или ту, что указал пользователь).
2. Помечай, что ей занимаешься; после выполнения — что выполнена.
3. После задач перепроверь файл: если появились новые — выполняй.
4. Каждая задача — отдельный коммит и пуш (как в `TASKS.md`).
5. **В том же коммите** обнови версию (см. ниже).

## Версия

Источник истины: поле `version` в `package.json`. UI берёт её через `__APP_VERSION__` (Vite `define`) и показывает в верхней панели (`src/App.tsx`): «версия …».

Формат: `0.<номер_задачи>[.<патч>]` — например `0.83`, `0.83.1`, `0.84`.

При завершении задачи обнови `version` в `package.json` и корневую запись в `package-lock.json`:

| Ситуация | Новая версия |
|----------|----------------|
| **Новая задача N** (первая реализация пункта N) | `0.N` (патч сбрасывается) |
| **Доработка** уже закрытого пункта (багфикс, уточнение) | +1 к третьему числу: `0.83` → `0.83.1` → `0.83.2` |

Если патча ещё нет (`0.83`), первая доработка → `0.83.1`.

Не меняй мажор (`0`) без отдельной просьбы пользователя.
