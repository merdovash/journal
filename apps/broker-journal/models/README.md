# Веса OCR

Локальная модель, которая читает текст со скриншота открытия сделки.

Это LSTM-веса Tesseract из набора `tessdata_fast` (языки `rus` и `eng`).
Источник: [tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast), лицензия Apache-2.0.

Файлы около 4 МБ каждый, вместе меньше 8 МБ, поэтому они лежат в git и подхватываются без скачивания. Распознавание работает офлайн и одинаково на любой машине. Крупную vision-модель (сотни мегабайт и больше) в репозиторий класть не стоит — для этого экрана достаточно OCR и разбора известной вёрстки Walt.
